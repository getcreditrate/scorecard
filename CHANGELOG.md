# Changelog

All notable changes to the framework and its documentation. Dates before 18 September 2026 are taken from the revision history of the Four Phase Implementation Plan and the version pages of the documents named; the repository itself begins on 18 September 2026.

## 2026-09-25

- Published the Phase 2 package to `phase2/`: Retrospective Validation Protocol v1.0, Partner Data Specification, Independent Validator Scope of Work, Code Readiness Record, `refit.py`, `disparate_impact.py`, and the results of the end-to-end run on the public population (holdout KS 21.9, PSI 0.009). The package was issued and presented to the board second line review function on 20 September 2026.
- README rewritten: status table, adoption walkthrough, roadmap, Phase 2 section; limitations updated to the restructured plan (per-institution calibration is now the first stage of Phase 3).
- Added `CHANGELOG.md` and `CITATION.cff`.

## 2026-09-20

- Phase 2 redefined as the validation protocol and onboarding standard, fixed before any institution's record is received. Per-institution calibration becomes the first stage of Phase 3. Four Phase Implementation Plan revision 5.0.
- Retrospective Validation Protocol v1.0 frozen. Both Phase 2 scripts written to the protocol and executed end to end on the public validation population.

## 2026-09-18

- Initial public release under the Apache License 2.0: `extract_matured.py`, `fit_scorecard.py`, `build_appendices.py`, `ablation.py`, `ablation_variant_f.py`, `variantF_results.json`, Model Validation Report with Addendum, Model Card and Explainability Architecture.
- Addendum to the Model Validation Report: Variant F (Variant D with debt to income ratio also removed) estimated; 76.7% of benchmark Gini on seven characteristics containing no credit bureau input. Version 1.1 of the addendum supersedes 1.0 issued the same day, which lettered the variant E in error.

## 2026-07-31

- Get Credit Rate Foundation incorporated in Delaware as a nonprofit corporation organized to qualify under Section 501(c)(3). Bylaws, conflict of interest policy, document retention policy and organizational consent adopted. Model Risk Management Policy and model inventory adopted by written consent; model risk owner appointed; two directors who are not the model developer constituted as the second line review function.

## 2025-10

- Model Validation Report v1.0 issued: Variants A to E, out-of-time validation on 2016 to 2017 vintages, calibration by decile, population stability, adverse action reason code output, stated limitations, reproduction scripts.
- Model Card and Explainability Architecture v1.0 issued.
- Technical Architecture and Four Phase Implementation Plan revision 4.0, revised following external review; validation results incorporated.
- Domain getcreditrate.com registered (11 October 2025); public information site live.

## 2025-08

- First engagement with a Treasury-certified CDFI on testing and piloting the framework.

## 2025-04

- Four Phase Implementation Plan revision 3.0: model development scope set, Weight of Evidence methodology confirmed, regulatory compliance framework drafted.

## 2024-11

- Four Phase Implementation Plan revision 2.0: model architecture and feature selection strategy revised; data foundation and alternative data integration approach updated.

## 2024

- Initial technical framework and four phase implementation plan. Model architecture, data strategy and deployment approach first documented (revision 1.0, working draft).
